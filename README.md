# Full-Stack NFT Marketplace

This repository contains the NFT marketplace frontend and its Hardhat smart-contract project.

## Project folders

- `nft-frontend/` — Next.js frontend.
- `nftMarketplace-starter-file-main/` — Hardhat project, Solidity contracts, and its accompanying app files.

Install dependencies from the folder you intend to work in:

```bash
cd nft-frontend
npm install
```

```bash
cd nftMarketplace-starter-file-main
npm install
```
